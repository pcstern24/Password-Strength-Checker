# Password Entropy Checker

## Overview
Password Entropy Checker is a cybersecurity application that analyzes password strength by calculating estimated entropy, evaluating character complexity, and estimating how long a password would take to crack using different attack methods. The project demonstrates password security concepts, mathematical analysis, and secure programming practices using Java.

## Features
- Calculates password entropy in bits
- Evaluates password complexity based on character types
- Checks for uppercase letters, lowercase letters, numbers, and special characters
- Estimates offline and online password cracking times
- Provides an overall password strength rating
- Generates a detailed password security report
